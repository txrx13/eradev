### 2. "3-layer enforcement" vs "4-layer architecture" Confusion
Two separate concepts are being conflated:
- **3-layer runtime enforcement** = CLAUDE.md auto-load + PreToolUse hook + memory persistence (this is about META behavior enforcement)

Both are correct and coexist. Documents need to distinguish them clearly. The skills/reference/README.md already lists both as separate bullets (lines 11-12) but labels them confusingly.

### 3. Universal Prompt in READMEs Lists 5-Step Loading
The "universal prompt" block in both READMEs shows 5 files to LOAD. Since v9, step 6 (domain skin) is conditional. The universal prompt should either add a note about conditional step 6 or remain as-is with a footnote.
