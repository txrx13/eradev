## 4. Метрики

> Вычисляются после каждого RT-3 или по запросу Meta-Agent.

| Метрика | Формула | Текущее значение | Порог |
|---------|---------|------------------|-------|
| B(agent) | F^w1 * E^w2 * (1-sigma)^w3 * Lambda^w4 | -- | > 0.5 |
| S_team | 1 - 2/(n(n-1)) * Sum\|Bi-Bj\| | -- | > 0.7 |
| P_coll | 1 - prod(1 - Bi^k) | -- | > 0.8 |
| fix rate | кол-во fix-коммитов / общее кол-во коммитов | -- | < 0.3 |
| fix chain | последовательных fix подряд | -- | < 3 (иначе BLOCK) |

> Компоненты B: F = фокус (прочитаны ли нужные файлы), E = выравнивание с задачей,
> sigma = противоречивость, Lambda = применение накопленного опыта.
> k в P_coll указывать явно. По умолчанию k=1.
> n в T(C) указывать явно при расчёте времени жизни конфигурации.
